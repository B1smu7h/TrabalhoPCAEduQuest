# EduQuest

Portal educacional gamificado desenvolvido individualmente para o PCA de Introdução a Aplicações Web.

## Objetivo

O EduQuest busca tornar a prática de conteúdos educacionais mais interativa por meio de desafios, feedback imediato e acompanhamento simples do progresso.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Status

Em desenvolvimento. O protótipo será construído progressivamente para a segunda etapa do PCA.

## Como executar

Quando os arquivos da aplicação forem adicionados, abra `index.html` no navegador. O projeto inicial não exige backend.

## Escopo inicial

- Portal inicial com navegação entre páginas.
- Desafios de múltipla escolha.
- Feedback sobre as respostas e pontuação em XP.
- Acompanhamento local do progresso com `localStorage`.
